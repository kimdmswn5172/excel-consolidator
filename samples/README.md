# 연습용 가상 엑셀 파일

실제 업무 자료나 개인정보가 아닌 **가짜 자료**입니다. 이름은 `직원001`, 사번은 `S0001`처럼 규칙으로 만들었습니다.
파일은 `node samples/make-samples.mjs`로 언제든 다시 만들 수 있습니다(같은 결과가 나옵니다).

## 파일 구성

- `마스터.xlsx`: 직원 100명의 마스터 표
- `부서/부서01.xlsx` ~ `부서20.xlsx`: 부서별 제출 파일 (부서마다 5명, 마스터와 같은 양식)
- `예외/`: 예외 상황 시험용 파일 4개

## 시트 양식 (마스터와 부서 파일 공통)

| 위치 | 내용 |
|---|---|
| 1행 | 제목 (A1:H1 병합. 데이터 영역 밖이라 취합에 영향 없음) |
| 3행 | 헤더: 연번, **사번**, 이름, 부서, 교육이수, 이수일, 점수, 비고 |
| 4행부터 | 데이터 |
| 기준 열 | B열 사번 |
| 취합 대상 열 | E~H열 (교육이수, 이수일, 점수, 비고) |

## 시험 사례

| 사례 | 파일 | 기대 동작 |
|---|---|---|
| 마스터 값이 부서 값과 다름 | 마스터 직원001 교육이수 `미이수`, 직원010 점수 `55` ↔ 부서 값 `이수`, `89` | 부서 값으로 바뀌고 "바뀐 칸" 목록에 2개가 나온다 |
| 마스터 값이 부서 값과 같음 | 마스터 직원002 교육이수 `이수` | 바뀐 칸에 넣지 않는다 |
| 부서 칸이 비어 있음 | 부서01 직원003, 부서02 직원007 (취합 대상 칸이 모두 빔) | 마스터에 있던 값을 그대로 유지한다 |
| 마스터에 없는 키 | 부서05의 `S9999` | 미매칭 목록에 표시한다 |
| 같은 파일 안 중복 키 | 부서07의 직원032 (두 번) | 사용자가 처리 방법을 고를 때까지 채우지 않는다 |
| 파일 사이 중복 키 | 부서12와 부서13의 직원060 | 위와 같다 |
| 키 표기 차이 | 부서11의 `s0052 `(소문자+공백), `Ｓ0053`(전각) | 키를 정리하면 `S0052`, `S0053`으로 마스터와 맞는다 |
| 병합 셀 위험 | 부서09 (기준 열 B5:B6 병합) | 취합하지 않고 이유를 알려 준다 |
| 데이터 영역 밖 병합 | 부서18 (데이터 아래 안내 문구 병합), 모든 파일의 제목 줄 | 문제없이 취합한다 |
| 헤더 다름 | 부서15 (`사번` 대신 `직원번호`) | 취합에서 제외하고 이유를 알려 준다 |
| 마스터 안 중복 키 | `예외/마스터_중복키.xlsx` (직원100이 두 번) | 중복 키로 처리한다 |
| 마스터 헤더 다름 | `예외/마스터_헤더다름.xlsx` | 점검 단계에서 경고한다 |
| 한셀(한컴오피스)로 저장한 파일 | `예외/마스터_한셀저장.xlsx` | 문제없이 읽히고 취합된다. (한셀은 태그에 `x:` 접두어를 붙여 저장해서 예전에는 "읽을 수 없는 파일"로 나왔다) |
| 손상된 파일 | `예외/손상.xlsx` | 읽을 수 없는 파일로 건너뛴다 |
| .xlsx가 아닌 파일 | `예외/목록.csv` | 목록에 넣지 않고 안내한다 |

## 주의

샘플 파일을 엑셀이나 한셀에서 열어 **저장하지 마세요.** 저장하면 파일이 바뀌어서 이 표의 기대 결과가 달라집니다. 열어 보려면 다른 곳에 복사한 뒤 여세요. 파일이 바뀌었다면 `node samples/make-samples.mjs`로 다시 만들 수 있습니다.

## 이 세트에 없는 것

- 비밀번호가 걸린 파일: 도구로 만들 수 없어서 넣지 못했습니다. 필요하면 엑셀에서 직접 만들어 `예외/`에 넣어 주세요.
- 크기가 큰 파일: 저장소에 넣기에는 너무 커서 넣지 않았습니다. 필요하면 `node samples/make-large-sample.mjs 200000`으로 만듭니다(20만 행, 약 9MB짜리 `큰마스터.xlsx`, `큰부서.xlsx`). 파일은 컴퓨터의 임시 폴더(`%TEMP%\my-app-large-samples`)에 생깁니다.
